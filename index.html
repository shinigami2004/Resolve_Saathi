The proposed product

One call.
Verified progress.

A bounded agent handles standard exchanges and hands uncertainty to a person.

Illustrative exchange workflow

No real order or system connection
  1. 01

    Listen + verify

    Understand a Hindi or English request. Verify the shopper before revealing order data.

  2. 02

    Check evidence

    Retrieve the order, brand policy, replacement stock and exchange eligibility.

  3. 03

    Offer + confirm

    Explain the available option and obtain the shopper’s explicit confirmation.

  4. 04

    Act + verify

    Create the request through an allowed API. Check its response before saying it succeeded.

Agent authority

Routine, policy-compliant actions

Order status and eligible exchanges after verification and confirmation.

Human approval or handoff

Exceptions need judgement

Refunds, policy exceptions, identity disputes, stock conflicts, failed APIs and unsupported cases.

A created request is an intermediate milestone. Track pickup and replacement completion separately. Log attempted actions, system responses and human overrides.

What becomes harder to replace

The validated brand configuration and useful history of resolved edge cases, if pilots show gains. A replacement must rebuild and revalidate that reliability.

Learning requires appropriate data permissions. Brands retain their data; approved, de-identified failure patterns can inform shared tests. More conversations alone do not establish an advantage.

Adoption, economics & trust

Value earns the renewal.

The brand buys only if the pilot proves reliable resolution at an acceptable total cost.

  1. Set up

    Connect policies and orders. Define approval limits.

  2. Pilot

    Review exchange actions and failures.

  3. Measure

    Compare time, reopen rate, errors and total cost.

  4. Renew

    Expand only if value and trust hold.

Porter’s five forces shape the strategy

Buyer power
Brands can switch. Prove value against their existing process.
Competitive rivalry
Rivals already take actions. Specialise in exchange outcomes.
Substitutes
Humans and BPOs remain alternatives. Test total resolution cost.
Supplier power
Speech, model and telephony vendors matter. Own workflow tests and keep provider options.
New entrants
Voice agents are accessible. Build tested cases and deployment knowledge.

India: proposed safeguards

Trust is part of the operation.

Provide clear data-use notices, limit access and retention, and keep action audit trails. Plan deployment around applicable DPDP requirements and their phased commencement.[4]

Count human escalation and integration work in the cost per resolved case.
